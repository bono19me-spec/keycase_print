# 폰트 사이즈 변경 메뉴 이동 계획

## 목적
- 4페이지(Step 4)에 있는 "폰트 사이즈 변경" 메뉴를 2페이지(Step 2)의 "추가 정보" 섹션 아래로 이동하여 사용자 편의성을 향상시킵니다.

## 변경 사항
### 1. index.html 수정
- `data-simple-step="4"` 섹션 내의 `<details class="simple-position-panel">` 블록을 찾습니다.
- 해당 블록을 `data-simple-step="2"` 섹션 내의 `id="simpleAdditionalInfo"`인 `<details>` 태그 바로 뒤로 이동시킵니다.
- 이동 시 `.selection-stack` div 내부에 위치하도록 하여 기존 옵션들과 일관된 스타일을 유지합니다.

### 2. 스타일 및 동작 확인
- Step 2의 테마 색상(`--step-color: #8a5a00`)이 메뉴에 자동으로 적용되는지 확인합니다.
- `app.js`에서 해당 메뉴의 입력 필드 및 버튼에 설정된 이벤트 리스너가 정상적으로 작동하는지 확인합니다. (ID 기반으로 바인딩되어 있으므로 위치 이동 후에도 정상 작동할 것입니다.)

## 작업 순서
1. `index.html`에서 소스 코드 추출 (Step 4의 메뉴 블록)
2. `index.html`에서 대상 위치 확인 (Step 2의 추가 정보 아래)
3. 코드 이동 적용
4. 브라우저에서 레이아웃 및 기능 테스트 (필요 시)
